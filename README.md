# Philosophers: High-Stakes Resources Management for Survival

## Description

**Philosophers** is a project of the old 42 curriculum (until December 2025)
that introduces students to the world of **concurrent programming** way
for computers to manage multiple tasks at the same time in one single executed
program (i.e. process) with shared resources. The project challenges students
to optimize usage and management of shared resources.
